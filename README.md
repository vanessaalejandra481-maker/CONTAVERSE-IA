# CONTAVERSE IA – Laboratorio Empresarial (Avance 6)

Aplicación educativa con gemelo digital organizacional N11 y simulador de dilemas N12.
Los resultados son **reglas locales y supuestos sintéticos**, no un servicio de IA generativa conectado ni asesoría profesional.
La integración del entorno virtual Frame (N13) **continúa pendiente**.

## Publicación en Streamlit Community Cloud

- Archivo principal: `streamlit_app.py`
- Rama de GitHub: `main` (o la rama principal que realmente figure en GitHub)
- Dependencias: `requirements.txt`

**Advertencias:** No introducir datos personales ni empresariales reales. Los CSV que cargues se procesan en la sesión; las decisiones se escriben en archivos temporales aislados por sesión, que **pueden perderse al reiniciar el servidor**. No existe almacenamiento permanente seguro ni control de acceso de producción.
